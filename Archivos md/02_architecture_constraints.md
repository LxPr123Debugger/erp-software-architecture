# 2. Restricciones de Arquitectura

## Decisiones Tecnológicas
* **Backend:** Desarrollo en **Java** con el framework **Spring Boot** para implementar servicios y APIs RESTful.
* **Base de Datos:** **PostgreSQL** como sistema gestor de base de datos relacional.
* **Frontend:** Single Page Application (SPA) construida con **React**.
* **Comunicación:** Protocolo HTTP/HTTPS utilizando arquitectura REST y formato JSON para el intercambio de datos.

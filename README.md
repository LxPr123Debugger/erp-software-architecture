# ERP Software Architecture - Módulo de Compras

Jose Leonardo Peñuela León

Repositorio de documentación de arquitectura para el módulo de compras de un sistema ERP (Enterprise Resource Planning), estructurado bajo la plantilla **arc42** y diagramado utilizando la notación **C4 Model** y **UML**.

---

## 📚 Estructura de la Documentación

Toda la documentación detallada del proyecto se encuentra en la carpeta [`Archivos md/`](./Archivos%20md/):

* [**01. Introducción y Objetivos**](./Archivos%20md/01_introduction_and_goals.md): Objetivos del negocio y requisitos principales del módulo de compras.
* [**02. Restricciones de Arquitectura**](./Archivos%20md/02_architecture_constraints.md): Decisiones tecnológicas (Java, Spring Boot, PostgreSQL, React).
* [**03. Alcance y Contexto (C1)**](./Archivos%20md/03_system_scope_and_context.md): Límites del sistema e interacciones externas.
* [**05. Vista de Bloques de Construcción (C2)**](./Archivos%20md/05_building_block_view.md): Contenedores y responsabilidades de la arquitectura.
* [**06. Vista de Ejecución y Modelo de Datos**](./Archivos%20md/06_runtime_view.md): Diagrama de Secuencia ("Registrar Producto") y Modelo Entidad-Relación.
* [**10. Glosario**](./Archivos%20md/10_glossary.md): Términos clave del dominio.
